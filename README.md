# Easygames web build

Published Defold + Rust WebAssembly assets only. Game source is maintained separately.

Play: https://dexus.github.io/easygames-web/

All six games support browser-local NPC play. Live private-room PvP requires a
separately hosted HTTPS Rust game server with CORS enabled for https://dexus.github.io.
GitHub Pages serves this static client; it does not run the multiplayer server.

Deploy this repository through GitHub Pages, branch `main`, folder `/ (root)`.
