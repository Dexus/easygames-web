NPC play runs in your browser. No account or server needed.

How to play & multiplayer

Choose a game, set NPC difficulty from 1 to 10,000, then take a seat. Touch and mouse are supported.

Live private-room PvP requires an HTTPS Rust game server. Enter its address in the game menu. GitHub Pages hosts this web client; it does not host multiplayer matches.

Local games reset when this page reloads. If loading fails, use a current browser with WebGL enabled and reload.
